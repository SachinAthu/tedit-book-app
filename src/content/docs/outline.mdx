The book is split into **ten volumes** plus a set of appendices. It follows a **theory-first** path: Volumes I–IX build the concepts, and Volume X turns them into a working editor.

<Aside type="note" title="Not sure where to start?">
  There are three ways through the book — read the theory first, mix and match,
  or jump straight to the implementation. See [the home page](/).
</Aside>
