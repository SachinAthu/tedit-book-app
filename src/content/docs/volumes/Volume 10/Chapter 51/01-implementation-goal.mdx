The Chapter 50 repository is the starting point for this milestone. I extracted the attached repository, configured the existing CMake project, built all targets, and ran the registered tests. All three tests—`smoke`, `editing`, and `file`—passed.

Chapter 51 will extend the existing implementation without replacing working modules or introducing the final input architecture prematurely.

## Implementation milestone

The File Manager will gain a complete save workflow:

1. Serialize the current `Document` into UTF-8, using LF line endings and the established trailing-newline policy.
2. Create a temporary file in the destination file's directory.
3. Write the complete serialized document, handling partial writes and interrupted system calls.
4. Close the temporary file successfully and atomically replace the destination using `rename()`.
5. Clear `EditorState.is_dirty` only after the replacement succeeds.
6. Preserve the in-memory document and Dirty Flag when saving fails.
7. Return control to the Event Loop after recoverable save errors, allowing the user to continue editing.

The implementation will follow ADR-020, ADR-021, and ADR-022. Durability through `fsync()`, file-metadata preservation, and automatic recovery of abandoned temporary files remain outside this milestone.
