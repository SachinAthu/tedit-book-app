## Introduction

Chapter 44 prepared a repository that could build and test a program, but that program did not yet do anything. Chapter 45 begins the editor itself by establishing its first executable runtime: the program must enter the terminal, accept raw input, run an event loop, and exit cleanly.

> **How does a terminal program take control of the terminal, remain interactive, and return the terminal to its original state?**

This chapter implements that foundation in small, verifiable steps. It creates the `terminal` module, saves and restores the original `termios` state, enables raw mode, makes the application lifecycle explicit in `main.c`, and adds a minimal event loop whose only command is Ctrl-Q. It then verifies the runtime manually in a real terminal and reviews the resulting project state. No document, cursor, renderer, input parser, or editing logic is introduced yet; the goal is a trustworthy runtime on which later chapters can build, with the existing build and smoke-test baseline still passing.
