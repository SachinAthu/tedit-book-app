Chapter 48 extends the existing editor so that the user can create and remove logical lines while editing text. We will continue directly from the Chapter 47 repository snapshot, preserving its existing modules and working behavior.

The supplied repository has been configured and built successfully in the verification environment. Both existing CTest tests, `smoke` and `editing`, pass before the Chapter 48 changes.

## Required behavior

| Operation                   | Required result                                                                          |
| --------------------------- | ---------------------------------------------------------------------------------------- |
| Press Enter                 | Split the current logical line at the Cursor.                                            |
| Split in the middle         | Keep the preceding text on the original line and move the remaining text to a new line.  |
| Split at column zero        | Insert an empty line before the existing text.                                           |
| Split at end-of-line        | Create an empty line after the current line.                                             |
| Backspace within a line     | Delete the character immediately before the Cursor.                                      |
| Backspace at column zero    | Merge the current line into the preceding line.                                          |
| Backspace on the first line | Do nothing.                                                                              |
| Successful line edit        | Update the Cursor, set the Dirty Flag, and redraw the screen.                            |
| Failed line edit            | Preserve the existing document contents and avoid marking an unsuccessful edit as dirty. |

For example, pressing Enter in the middle of `hello world` should produce:

Before:

```
hello| world
```

After:

```
hello
| world
```

Here, `|` represents the Cursor. The original text is preserved, and the Cursor moves to the beginning of the new line.

For Backspace at the beginning of the second line:

Before:

```
hello
|world
```

After:

```
hello|world
```

The Cursor moves to the former end of the preceding line.

The existing Cursor module interface, Editor State structure, Renderer, Terminal module, and CMake configuration will remain unchanged.
