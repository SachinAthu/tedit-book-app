## Introduction

Chapter 52 completed the visible interface and the input-to-command path, but several everyday keys still did nothing. Home, End, Delete, Page Up, Page Down, and Tab were not recognized, and tabs and non-ASCII input exposed the difference between logical character positions and terminal display columns.

> **How can the editor support the remaining keyboard operations while keeping logical cursor positions, visual columns, and input handling consistent?**

This chapter closes those gaps incrementally. It extends terminal sequence parsing, adds Home/End and page navigation, implements Delete including line merging, and supports tab insertion with a configurable tab width. It then handles UTF-8 keyboard input at character boundaries, introduces a shared logical-to-visual column mapping for tabs and Unicode display widths, and routes the new events through the Input Engine and Command Engine. It finishes with status-bar refinements, vertical-navigation tests, and pseudo-terminal checks so navigation and rendering agree for both plain and non-ASCII text.
