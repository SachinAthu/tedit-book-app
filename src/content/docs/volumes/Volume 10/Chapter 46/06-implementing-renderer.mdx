title: 46.6 Implementing the Renderer
description: "Implements the Renderer to build frames from Editor State, write them to the terminal, and position the cursor without modifying editor state."
---

The Screen Buffer now provides an in-memory representation of the terminal's visible characters. The next step is to connect that buffer to the Editor State and display it on the terminal.

The Renderer has three responsibilities:

1. Build the frame by reading the Document and copying visible characters into the Screen Buffer.
2. Display the frame by writing terminal control sequences and screen contents to standard output.
3. Position the terminal cursor according to the Editor State.

The Renderer must not modify the Document or Cursor. It is a read-only consumer of the Editor State.

## Renderer Interface

Create `src/renderer/renderer.h`:

```c
/* src/renderer/renderer.h */

#ifndef RENDERER_RENDERER_H
#define RENDERER_RENDERER_H

#include <stdbool.h>
#include <stddef.h>

#include "../state/editor_state.h"
#include "screen_buffer.h"

typedef struct
{
    ScreenBuffer screen_buffer;
    char *output_buffer;
    size_t output_capacity;
} Renderer;

bool renderer_init(Renderer *renderer, size_t rows, size_t columns);

void renderer_destroy(Renderer *renderer);

bool renderer_render(Renderer *renderer, const EditorState *state);

#endif
```

The `Renderer` owns its Screen Buffer. The terminal dimensions are provided during initialization, so this implementation does not yet need to discover terminal dimensions itself.

The public interface deliberately hides the internal rendering steps. Other modules only need to initialize the Renderer, request a frame, and release its resources.

## Building the Frame

Create `src/renderer/renderer.c`:

```c
/* src/renderer/renderer.c */

#include "renderer.h"

#include <errno.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>

static bool renderer_build_frame(Renderer *renderer, const EditorState *state);

static bool renderer_write_frame(Renderer *renderer);

static bool renderer_ensure_output_capacity(Renderer *renderer, size_t required);

static bool renderer_write_all(const char *data, size_t length);

static bool renderer_write_cursor_position(size_t row, size_t column);

bool renderer_init(Renderer *renderer, size_t rows, size_t columns)
{
    if (renderer == NULL)
    {
        return false;
    }

    renderer->screen_buffer.cells = NULL;
    renderer->screen_buffer.rows = 0;
    renderer->screen_buffer.columns = 0;
    renderer->output_buffer = NULL;
    renderer->output_capacity = 0;

    return screen_buffer_init(&renderer->screen_buffer, rows, columns);
}

void renderer_destroy(Renderer *renderer)
{
    if (renderer == NULL)
    {
        return;
    }

    screen_buffer_destroy(&renderer->screen_buffer);

    free(renderer->output_buffer);
    renderer->output_buffer = NULL;
    renderer->output_capacity = 0;
}

bool renderer_render(Renderer *renderer, const EditorState *state)
{
    bool success;

    if (renderer == NULL || state == NULL)
    {
        return false;
    }

    if (!renderer_build_frame(renderer, state))
    {
        return false;
    }

    /*
     * Hide the terminal text cursor while drawing.
     */
    if (!renderer_write_all("\x1b[?25l", 6))
    {
        return false;
    }

    success = renderer_write_frame(renderer);

    if (success)
    {
        success = renderer_write_cursor_position(
            state->cursor.row,
            state->cursor.column);
    }

    /*
     * Always attempt to restore cursor visibility,
     * even if frame rendering fails.
     */
    if (!renderer_write_all("\x1b[?25h", 6))
    {
        success = false;
    }

    return success;
}

static bool renderer_build_frame(Renderer *renderer, const EditorState *state)
{
    if (renderer == NULL || state == NULL)
    {
        return false;
    }

    if (renderer->screen_buffer.cells == NULL)
    {
        return false;
    }

    /* Start from a clean slate: every cell becomes a blank space. */
    screen_buffer_clear(&renderer->screen_buffer, ' ');

    /* For each visible screen row... */
    for (size_t row = 0; row < state->document.line_count && row < renderer->screen_buffer.rows; row++)
    {
        const DocumentLine *line = &state->document.lines[row];

        /* ...copy each character of that line into the matching screen cell. */
        for (size_t column = 0; column < line->length && column < renderer->screen_buffer.columns; column++)
        {
            if (!screen_buffer_set(&renderer->screen_buffer, row, column, line->data[column]))
            {
                return false;
            }
        }
    }

    return true;
}
```

The frame-building function first fills every cell with a space. It then copies characters from each visible Document line into the corresponding Screen Buffer row.

This approach handles both shorter and longer documents:

- Lines shorter than the terminal width are followed by blank cells.
- Lines longer than the terminal width are clipped at the right edge.
- Document lines below the visible terminal height are not rendered.
- Empty lines remain blank.

The implementation accesses `DocumentLine.data` using its explicit `length`. It does not treat the line as a null-terminated C string.

## Writing the Frame to the Terminal

Add the following functions to the end of `src/renderer/renderer.c`:

```c
static bool renderer_ensure_output_capacity(Renderer *renderer, size_t required)
{
    if (renderer == NULL)
    {
        return false;
    }

    if (required <= renderer->output_capacity)
    {
        return true;
    }

    char *larger = realloc(renderer->output_buffer, required);
    if (larger == NULL)
    {
        return false;
    }

    renderer->output_buffer = larger;
    renderer->output_capacity = required;

    return true;
}

static bool renderer_write_frame(Renderer *renderer)
{
    const ScreenBuffer *buffer;
    char sequence[64];
    size_t frame_length;
    size_t position;

    if (renderer == NULL)
    {
        return false;
    }

    buffer = &renderer->screen_buffer;

    if (buffer->cells == NULL)
    {
        return false;
    }

    /* First pass: measure the frame to size the output buffer exactly. */
    frame_length = 0;

    for (size_t row = 0; row < buffer->rows; row++)
    {
        int sequence_length;
        size_t row_length;

        /*
         * Move the cursor to the start of this row. Format "\x1b[<row>;1H"
         * means "go to line <row>, column 1". Doing this for every row avoids
         * relying on the terminal to wrap lines automatically.
         */
        sequence_length = snprintf(sequence, sizeof(sequence), "\x1b[%zu;1H", row + 1);

        if (sequence_length < 0 || (size_t)sequence_length >= sizeof(sequence))
        {
            return false;
        }

        row_length = (size_t)sequence_length + buffer->columns;

        if (frame_length > SIZE_MAX - row_length)
        {
            return false;
        }

        frame_length += row_length;
    }

    if (!renderer_ensure_output_capacity(renderer, frame_length))
    {
        return false;
    }

    /* Second pass: copy the escape sequences and characters into the buffer. */
    position = 0;

    for (size_t row = 0; row < buffer->rows; row++)
    {
        int sequence_length;

        sequence_length = snprintf(sequence, sizeof(sequence), "\x1b[%zu;1H", row + 1);

        if (sequence_length < 0 || (size_t)sequence_length >= sizeof(sequence))
        {
            return false;
        }

        memcpy(renderer->output_buffer + position, sequence, (size_t)sequence_length);
        position += (size_t)sequence_length;

        /* Copy each character in the row, left to right. */
        for (size_t column = 0; column < buffer->columns; column++)
        {
            const ScreenCell *cell = screen_buffer_get(buffer, row, column);

            if (cell == NULL)
            {
                return false;
            }

            renderer->output_buffer[position] = cell->character;
            position++;
        }
    }

    return renderer_write_all(renderer->output_buffer, frame_length);
}

static bool renderer_write_cursor_position(size_t row, size_t column)
{
    char sequence[64];
    int sequence_length;

    sequence_length = snprintf(sequence, sizeof(sequence), "\x1b[%zu;%zuH", row + 1, column + 1);

    if (sequence_length < 0 || (size_t) sequence_length >= sizeof(sequence))
    {
        return false;
    }

    return renderer_write_all(sequence, (size_t) sequence_length);
}

static bool renderer_write_all(const char *data, size_t length)
{
    if (data == NULL)
    {
        return false;
    }

    size_t written = 0;

    while (written < length)
    {
        ssize_t result;

        /* Ask the OS to write the remaining bytes. */
        result = write(STDOUT_FILENO, data + written, length - written);

        if (result < 0)
        {
            /* EINTR means a signal interrupted us; retrying is safe. */
            if (errno == EINTR)
            {
                continue;
            }

            return false;
        }

        /* A return value of 0 means nothing could be written; give up. */
        if (result == 0)
        {
            return false;
        }

        written += (size_t)result;
    }

    return true;
}
```

### Why use `write()` instead of `printf()`?

The Renderer writes directly to standard output because terminal output is part of the low-level terminal interface. Using `write()` also lets the implementation handle partial writes and interruptions explicitly.

The `renderer_write_all()` function continues until all requested bytes have been written, unless an unrecoverable error occurs.

The escape sequences perform the following operations:

| Sequence          | Purpose                                       |
| ----------------- | --------------------------------------------- |
| `ESC[H`           | Move the terminal cursor to the home position |
| `ESC[2J`          | Clear the visible terminal screen             |
| `ESC[row;columnH` | Move the cursor to a specific position        |

Here, `ESC` represents the escape byte, `\x1b` in C.

Each row is positioned explicitly before its characters are written. This avoids depending on the terminal's automatic line-wrapping behavior when a row reaches the last column.

## Positioning the Cursor

After drawing the Screen Buffer, `renderer_render()` moves the terminal cursor to the position stored in the Editor State.

The Document and Cursor use zero-based coordinates, while ANSI cursor-position sequences use one-based coordinates. Therefore, the Renderer adds one to each coordinate.

For example, an Editor State cursor at row `0`, column `4` is positioned using:

```
"\x1b[1;5H"
```

The Renderer does not change the logical Cursor when displaying it.

Important limitation: This first implementation does not yet include a Viewport. If the Cursor moves beyond the visible terminal dimensions, the Renderer can attempt to position the terminal cursor outside the intended screen area. Later scrolling and Viewport integration must ensure that the visible cursor position is valid.

## Rendering Invariants

The Renderer should preserve these invariants:

- The Renderer does not modify the Editor State.
- Every frame starts with a cleared Screen Buffer.
- Only characters within the visible terminal dimensions are copied.
- Unused screen cells contain spaces.
- The terminal cursor position is derived from the logical Cursor.
- Failed output operations are reported to the caller.

At this point, the Renderer can build and display a complete frame. It is not yet connected to the application's event loop, and the current `main.c` does not call it.

The next section should integrate the Renderer into the application so the first editable screen appears when the editor starts.
